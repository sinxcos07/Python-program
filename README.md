# Python Programs 🐍

A collection of Python programs created while learning and practicing Python programming.

## Getting Started

Clone the repository:

```bash
git clone https://github.com/sinxcos07/Python-program.git
```

Navigate to the project folder:

```bash
cd Python-program
```

Run any Python file:

```bash
python filename.py
```

## Purpose

This repository serves as a personal collection of Python practice programs and exercises to strengthen programming fundamentals and problem-solving skills.
